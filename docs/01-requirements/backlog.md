# Product Backlog

Backlog รวมของโปรเจกต์ ทุกรายการต้องอ้างอิงกลับไปยังเอกสาร spec ใน [[01-spec/index|01-spec]] ได้เสมอ

- **ความสำคัญ**: MoSCoW — Must / Should / Could / Won't
- **สถานะ**: ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว / ยกเลิก
- รายการที่ถูกยกเลิกไม่ต้องลบ ให้เปลี่ยนสถานะเป็น "ยกเลิก" แล้วคงบรรทัดไว้ เพื่อรักษาประวัติการตัดสินใจ
- ตารางนี้เป็นแบบ append-only — ไม่แก้ไขหรือเรียงเลข ID ใหม่
- `(draft)` หลังชื่อ spec หมายถึงเอกสารต้นทางยังไม่ผ่านการอนุมัติ **เริ่มลงมือทำได้ แต่ข้อกำหนดยังเปลี่ยนได้** เครื่องหมายนี้จะถูกล้างเมื่อ spec ได้รับอนุมัติ
